## Kalathmi portfolio (vanilla)

### Run locally

From this folder:

```bash
python3 -m http.server 5173
```

Open `http://localhost:5173`.

### Edit content + links

- **Main page content**: `index.html`
- **Styling**: `styles.css`
- **Links + Spotify embed + interactive model logic**: `main.js`

In `main.js`, update:

- `LINKS.email`
- `LINKS.linkedin`
- `LINKS.github`
- `LINKS.spotifyPlaylistUrl` (optional)
- `LINKS.spotifyEmbedUrl` (optional Spotify iframe URL)

### Assets

Web-safe renamed images are in `assets/web/`.
